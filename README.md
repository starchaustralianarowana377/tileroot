# 🪟 tileroot - Manage your desktop layouts with ease

[![](https://img.shields.io/badge/Download-Release_Page-blue.svg)](https://github.com/starchaustralianarowana377/tileroot/releases)

## 📋 About this software

Tileroot saves your window arrangements. You can restore these setups whenever you need them. This tool works with your tiling window manager to keep your workspace organized. It saves time by remembering where you put your windows. You no longer need to move windows manually after a restart.

## 🚀 Getting Started

You do not need to write code to use this tool. Follow these steps to set up the software on your computer.

1. Go to the [releases page](https://github.com/starchaustralianarowana377/tileroot/releases).
2. Look for the latest version at the top of the list.
3. Click the link that ends in .exe to start the download.
4. Save the file to your desktop or a folder you can find.
5. Double-click the file to open the program.

## 🛠 How to save a layout

Once the program runs, it shows a list of your open windows. You can save the current positions of these windows.

1. Open the windows you want to arrange.
2. Position the windows on your screen.
3. Click the Save button inside tileroot.
4. Type a name for your layout in the box.
5. Press the Enter key on your keyboard.

The program creates a file that contains the geometry of your windows. This file stays on your computer until you delete it.

## 🔄 How to restore a layout

You can return to a saved setup at any time. This is useful after you reboot your computer or close your windows.

1. Open tileroot.
2. Select the name of the layout from the list.
3. Click the Restore button.
4. Watch as the program moves your windows to their saved spots.

## ⚙️ Configuration settings

You can change how the program behaves by opening the settings menu. Click the gear icon in the corner of the window.

- Start at login: Check this box if you want your layouts ready when your computer turns on.
- Auto-save: Check this box to keep your layouts updated while you work.
- File path: Use this box to choose where the software stores your layout files.

## 💻 System requirements

This tool runs on Windows 10 and Windows 11. It requires enough memory to keep your open windows tracked. Most modern computers have enough power to run tileroot without any issues. Keep your operating system updated to ensure the best performance.

## 💡 Common questions

Do I need to run this program in the background?
You can close the window after you save or restore a layout. The program does not need to stay open.

What happens if a window is missing?
If you close a program before you restore a layout, tileroot will try to open it for you. It matches the window to the layout if the program is installed.

Is my data safe?
Tileroot only stores the location and size of your windows. It does not look at your personal files or sensitive information.

## 🛡 Troubleshooting

If the program does not move a window, check if the program is minimized. Some applications do not allow external tools to move them when they are hidden. Bring the window to the front and try the restore button again.

If you have issues, ensure you downloaded the latest version from the link provided. Restart your computer if the windows seem stuck.
